# Week 11 -- cost per query, by stage

Generated by `python -m scripts.w11_cost_report` from trace logs. **Caveats that apply to every number below:** the model is the offline stub, so tokens are *estimated* (a heuristic over the real prompts and replies) and cost is a *projection* at the configured model's list price (`claude-opus-5`, $5/$25 per million tokens in/out); the stub's model call takes microseconds, so latency is dominated by retrieval and orchestration, not by a model. The *shape* (which stage the money is in) is robust; the absolute latency of a live model call is not measured.

**`ask` costs $0 because every one of its requests was gated -- a bug this table exposed, not a saving.** The drill log was generated in hybrid retrieval mode, which reports fused RRF scores (~0.033 at most) while the relevance gate compares against a cosine floor of 0.12, so no question ever reached the model and `output.found` was false for all of them.
